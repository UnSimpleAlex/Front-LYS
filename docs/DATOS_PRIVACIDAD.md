# Datos y Privacidad — Leña y Sabores

## Principio
Recopilar únicamente datos necesarios.

Clasificar información como pública, interna, personal, sensible o secreta.

## Reglas
- Minimizar duplicación de datos personales.
- Aplicar mínimo privilegio.
- No copiar datos personales completos a logs sin necesidad.
- Usar datos ficticios/anonimizados en desarrollo.
- Proteger exportaciones como operaciones sensibles.
- Revisar qué datos se envían a terceros y por qué.
- No usar datos de clientes para pruebas, demos o IA externa sin base legítima/autorización aplicable.
