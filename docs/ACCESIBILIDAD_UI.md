# Accesibilidad y Calidad de Interfaz — Leña y Sabores

- Preferir HTML semántico (`button`, `nav`, `main`, `form`, `label`, `table`).
- Acciones principales utilizables con teclado.
- Foco visible y orden lógico.
- Inputs con label/nombre accesible.
- Errores claros.
- Contraste suficiente; no depender solo del color.
- `alt` útil en imágenes informativas.
- Probar móvil, tablet y desktop.
- Animaciones deben aportar valor y considerar reducción de movimiento.
- Mantener estados claros de loading, empty, error y success.
